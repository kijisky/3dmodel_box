# Коробка для хранения метизов

Параметрическая 3D-модель (CadQuery) органайзера для метизов — винтов,
гаек, шайб и т.п. Рассчитана на печать на **ANYCUBIC Kobra S1**
(рабочая область 250×250×250 мм, CoreXY) плашмя, без поддержек.

## Модель сетки отсеков

Коробка делится на **строки** (по Y, вдоль длины). Каждая строка занимает
полную внутреннюю ширину коробки и делится на **свои** колонки (по X) —
независимо от других строк. Это значит:

- у разных строк может быть разное число ячеек;
- ширина каждой ячейки внутри строки задаётся независимо;
- сетка не обязана быть "таблицей" — ячейки соседних строк не обязаны
  совпадать по X.

## Параметры

| Параметр | CLI-флаг | По умолчанию | Описание |
|---|---|---|---|
| Ширина коробки | `--width` | 190 мм | внешний размер по X |
| Длина коробки | `--length` | 130 мм | внешний размер по Y |
| Высота (глубина) коробки | `--height` | 30 мм | внешний размер по Z |
| Толщина стенок | `--wall` | 2 мм | толщина внешних стенок, дна и перегородок |
| Число строк | `--rows` | 4 | строки идут по короткой стороне (Y) |
| Колонок в строке | `--cols` | 6 | одинаковое число колонок для всех строк (по длинной стороне, X) |
| Колонок по строкам | `--row-cols` | — | своё число колонок для каждой строки через запятую, напр. `3,6,6,6`; переопределяет `--cols` |
| Радиус скругления отсеков | `--radius` | 3 мм | скругление внутренних вертикальных углов каждой ячейки |
| Длины строк | `--row-sizes` | равномерно | список мм через запятую (по Y), переопределяет равное деление |
| Ширины ячеек по строкам | `--row-col-sizes` | равномерно | ширины каждой ячейки каждой строки (мм); группы строк разделены `\|`, ширины внутри строки — запятой |

По умолчанию получается коробка 190×130×30 мм: 4 строки по короткой
стороне (130 мм), в каждой строке по 6 колонок вдоль длинной стороны
(190 мм) — 24 одинаковых отсека.

Если заданы `--row-sizes` / `--row-col-sizes`, суммы значений должны точно
заполнять внутреннее пространство за вычетом перегородок:
`sum(sizes) == доступный_размер − толщина_стенки×(N−1)`, где
`доступный_размер = внешний_размер − 2×толщина_стенки`.
При несовпадении скрипт выбросит понятную ошибку с подсказкой.

## Установка

```bash
pip install -r requirements.txt
```

## Генерация STL

```bash
# модель по умолчанию (190x130x30, 4 строки x 6 колонок)
python3 models/fastener_box.py --out stl/fastener_box_190x130x30_6x4.stl

# кастомные габариты и равномерная сетка
python3 models/fastener_box.py --width 200 --length 150 --height 40 \
  --wall 2.5 --rows 3 --cols 5 --radius 4 \
  --out stl/my_box.stl

# разное число ячеек в разных строках: в первой строке 3 широкие ячейки,
# в остальных трёх — по 6 обычных
python3 models/fastener_box.py --row-cols 3,6,6,6 \
  --out stl/fastener_box_190x130x30_mixed_rows.stl

# полностью произвольная сетка: своя высота строки, число ячеек и их
# ширина в каждой строке независимо (не таблица)
python3 models/fastener_box.py --rows 3 \
  --row-cols 2,4,1 \
  --row-sizes 40,42,40 \
  --row-col-sizes "100,84|30,50,40,60|186" \
  --out stl/fastener_box_example_freeform.stl

# дополнительно сохранить STEP для редактирования в CAD
python3 models/fastener_box.py --step stl/fastener_box.step
```

Модель также можно импортировать программно:

```python
from models.fastener_box import build_fastener_box

# равномерная сетка
model = build_fastener_box(box_width=190, box_length=130, box_height=30,
                            wall_thickness=2, num_rows=4, row_cols=6,
                            corner_radius=3)

# произвольная сетка: 3 строки, разное число ячеек и их ширина в каждой
model = build_fastener_box(
    num_rows=3,
    row_cols=[2, 4, 1],              # число ячеек в каждой строке
    row_sizes=[40, 42, 40],          # высота (по Y) каждой строки
    row_col_sizes=[[100, 84], [30, 50, 40, 60], [186]],  # ширина ячеек в каждой строке
)
```

## Готовые STL в этом репозитории

- `stl/fastener_box_190x130x30_6x4.stl` — модель по умолчанию (4 строки x 6 колонок, равномерная сетка).
- `stl/fastener_box_190x130x30_mixed_rows.stl` — первая строка из 3 широких ячеек, остальные строки — по 6 обычных.
- `stl/fastener_box_example_freeform.stl` — полностью произвольная сетка (разная высота строк, разное число и ширина ячеек в каждой строке).

## Рекомендации по печати (Kobra S1)

- Печать плашмя дном вниз, поддержки не требуются.
- Высота слоя 0.2 мм; толщина стенок 2 мм ≈ 5 периметров при сопле 0.4 мм —
  для меньшей толщины стенок уменьшайте число периметров соответственно.
- Заполнение 15–20 % достаточно, так как модель — по сути короб с тонкими
  стенками и перегородками.
- Скругления внутренних углов отсеков (по умолчанию 3 мм) облегчают
  выемку мелких деталей пальцами.

## Планы
