# Коробка для хранения метизов

Параметрическая 3D-модель (CadQuery) органайзера для метизов — винтов,
гаек, шайб и т.п. Рассчитана на печать на **ANYCUBIC Kobra S1**
(рабочая область 250×250×250 мм, CoreXY) плашмя, без поддержек.

## Модель сетки отсеков

Коробка делится на **строки** (по Y, вдоль длины). Каждая строка занимает
полную внутреннюю ширину коробки и делится на **свои** колонки (по X) —
независимо от других строк. Это значит:

- у разных строк может быть разное число ячеек;
- ширина каждой ячейки внутри строки задаётся независимо;
- сетка не обязана быть "таблицей" — ячейки соседних строк не обязаны
  совпадать по X.

## Параметры

| Параметр | CLI-флаг | По умолчанию | Описание |
|---|---|---|---|
| Ширина коробки | `--width` | 190 мм | внешний размер по X |
| Длина коробки | `--length` | 130 мм | внешний размер по Y |
| Высота (глубина) коробки | `--height` | 30 мм | внешний размер по Z |
| Толщина стенок | `--wall` | 2 мм | толщина внешних стенок, дна и перегородок |
| Число строк | `--rows` | 4 | строки идут по короткой стороне (Y) |
| Колонок в строке | `--cols` | 6 | одинаковое число колонок для всех строк (по длинной стороне, X) |
| Колонок по строкам | `--row-cols` | — | своё число колонок для каждой строки через запятую, напр. `3,6,6,6`; переопределяет `--cols` |
| Радиус скругления отсеков | `--radius` | 3 мм | скругление внутренних вертикальных углов каждой ячейки |
| Длины строк | `--row-sizes` | равномерно | список мм через запятую (по Y), переопределяет равное деление |
| Ширины ячеек по строкам | `--row-col-sizes` | равномерно | ширины каждой ячейки каждой строки (мм); группы строк разделены `\|`, ширины внутри строки — запятой |

По умолчанию получается коробка 190×130×30 мм: 4 строки по короткой
стороне (130 мм), в каждой строке по 6 колонок вдоль длинной стороны
(190 мм) — 24 одинаковых отсека.

Если заданы `--row-sizes` / `--row-col-sizes`, суммы значений должны точно
заполнять внутреннее пространство за вычетом перегородок:
`sum(sizes) == доступный_размер − толщина_стенки×(N−1)`, где
`доступный_размер = внешний_размер − 2×толщина_стенки`.
При несовпадении скрипт выбросит понятную ошибку с подсказкой.

## Крышка: шарнир + защёлка, стекирование

По умолчанию скрипт генерирует **три** STL: короб, крышку и шпильку
шарнира. Крышка **не снимается целиком** — она навешена на шарнир с одной
(длинной) стороны короба и открывается/закрывается поворотом, как у
чемодана; с противоположной стороны она держится защёлкой-замком, которую
можно отстегнуть.

- **Шарнир** (`hinge_wall`, по умолчанию `south`) — вдоль этой стенки на
  коробе и на крышке формируется ряд чередующихся цилиндрических петель
  (короб/крышка/короб/крышка/короб — `--hinge-knuckle-count`, по
  умолчанию 5), с общим отверстием под стержень. После печати в
  отверстия продевается отдельная деталь-шпилька (`..._pin.stl`,
  диаметр `--hinge-pin-diameter`, по умолчанию 3 мм — подходит кусок
  прутка, гвоздь без шляпки, спица или отрезок толстой лески/прутка от
  3D-принтера) — она и становится осью вращения. Отключается флагом
  `--no-hinge` — тогда крышка снова полностью съёмная, с защёлками со
  всех задействованных сторон (как раньше).
- **Защёлка-замок** — на противоположной шарниру стенке (и по умолчанию
  больше нигде) на внешней стенке короба формируется небольшой
  купол-выступ. В юбке крышки, ровно напротив него, с обеих сторон
  прорезаны узкие щели (`--snap-arm-gap`), отделяющие гибкий язычок
  шириной `--snap-arm-width` от остальной (жёсткой) юбки — держится он
  только сверху, на панели крышки, и может пружинить. На язычке —
  ответное углубление под выступ. Язычок продолжается ниже юбки на
  `--snap-tab-length` мм с небольшим наплывом наружу (`--snap-flare`) —
  этот выступающий кончик хорошо виден и удобно берётся пальцами.
  Чтобы отстегнуть: подцепите/отогните язычок наружу за выступающий
  кончик, пока выступ не выйдет из углубления, и откройте крышку на
  шарнире — инструмент не нужен, защёлка не ломается. Отключается флагом
  `--no-snap` (тогда крышка держится только посадкой с натягом на
  свободных от шарнира сторонах).
- **Стекирование** — на верхней стороне крышки формируется приподнятый
  бортик, внутренний размер которого равен внешнему периметру короба
  (+ зазор `--stack-clearance`). Следующий короб, поставленный сверху,
  дном садится внутрь этого бортика и не соскальзывает — короба стекуются
  друг на друга так же, как если бы каждый следующий просто стоял на
  предыдущем. Отключается флагом `--no-stacking`.

Дополнительные флаги шарнира: `--hinge-wall` (`north`/`south`/`east`/
`west` — какая стенка становится осью), `--hinge-knuckle-diameter`,
`--hinge-knuckle-count`, `--hinge-knuckle-gap` (зазор между соседними
петлями), `--hinge-margin` (отступ ряда петель от боковых стенок),
`--hinge-pin-clearance` (зазор шпильки в отверстии — свобода вращения).

Дополнительные флаги защёлки: `--snap-diameter`/`--snap-height` (размер
купола-выступа), `--snap-long`/`--snap-short` (число защёлок на длинных/
коротких стенках, кроме стенки шарнира), `--snap-arm-width` (ширина
гибкого язычка), `--snap-arm-gap` (ширина прорези, отделяющей язычок),
`--snap-tab-length` и `--snap-flare` (длина и наплыв выступающего кончика
для захвата).

Крышка и шпилька всегда должны генерироваться с теми же `--width/
--length/--height/--wall`, что и короб, к которому они предназначены —
иначе не подойдут.

## Генерация STL

```bash
# модель по умолчанию (190x130x30, 4 строки x 6 колонок) + крышка на шарнире + шпилька
python3 models/fastener_box.py --out stl/fastener_box_190x130x30_6x4.stl
# -> ..._6x4.stl (короб), ..._6x4_lid.stl (крышка), ..._6x4_pin.stl (шпилька шарнира)

# шарнир на короткой стенке вместо длинной
python3 models/fastener_box.py --hinge-wall east --out stl/box_east_hinge.stl

# полностью съёмная крышка (без шарнира), как в предыдущей версии модели
python3 models/fastener_box.py --no-hinge --out stl/box_removable_lid.stl

# кастомные габариты и равномерная сетка
python3 models/fastener_box.py --width 200 --length 150 --height 40 \
  --wall 2.5 --rows 3 --cols 5 --radius 4 \
  --out stl/my_box.stl

# разное число ячеек в разных строках: в первой строке 3 широкие ячейки,
# в остальных трёх — по 6 обычных; крышка не нужна — та же, что у базовой модели
python3 models/fastener_box.py --row-cols 3,6,6,6 --no-lid \
  --out stl/fastener_box_190x130x30_mixed_rows.stl

# полностью произвольная сетка: своя высота строки, число ячеек и их
# ширина в каждой строке независимо (не таблица)
python3 models/fastener_box.py --rows 3 \
  --row-cols 2,4,1 \
  --row-sizes 40,42,40 \
  --row-col-sizes "100,84|30,50,40,60|186" \
  --no-lid --out stl/fastener_box_example_freeform.stl

# короб без крышки/защёлок/стекирования — просто открытый лоток
python3 models/fastener_box.py --no-lid --out stl/simple_tray.stl

# без защёлок (только посадка с натягом) или без бортика для стекирования
python3 models/fastener_box.py --no-snap --out stl/box_no_snap.stl
python3 models/fastener_box.py --no-stacking --out stl/box_no_stack.stl

# дополнительно сохранить STEP короба для редактирования в CAD
python3 models/fastener_box.py --step stl/fastener_box.step
```

Модель также можно импортировать программно:

```python
from models.fastener_box import build_fastener_box, build_lid, build_box_and_lid

# равномерная сетка, только короб
model = build_fastener_box(box_width=190, box_length=130, box_height=30,
                            wall_thickness=2, num_rows=4, row_cols=6,
                            corner_radius=3)

# произвольная сетка: 3 строки, разное число ячеек и их ширина в каждой
model = build_fastener_box(
    num_rows=3,
    row_cols=[2, 4, 1],              # число ячеек в каждой строке
    row_sizes=[40, 42, 40],          # высота (по Y) каждой строки
    row_col_sizes=[[100, 84], [30, 50, 40, 60], [186]],  # ширина ячеек в каждой строке
)

# короб + подходящая крышка + шпилька шарнира одним вызовом
# (используют общие box_* параметры; pin равен None при hinge_enabled=False)
base, lid, pin = build_box_and_lid(box_width=190, box_length=130, box_height=30,
                                    row_cols=6, num_rows=4)
```

## Готовые STL в этом репозитории

- `stl/fastener_box_190x130x30_6x4.stl` — короб по умолчанию (4 строки x 6 колонок, равномерная сетка), с петлями шарнира и защёлкой.
- `stl/fastener_box_190x130x30_6x4_lid.stl` — крышка к нему (на шарнире + защёлка + бортик для стекирования).
- `stl/fastener_box_190x130x30_6x4_pin.stl` — шпилька шарнира.
- `stl/fastener_box_190x130x30_mixed_rows.stl` — первая строка из 3 широких ячеек, остальные строки — по 6 обычных (короб напечатан без крышки, `--no-lid`; подходит под ту же крышку/шпильку).
- `stl/fastener_box_example_freeform.stl` — полностью произвольная сетка (разная высота строк, разное число и ширина ячеек в каждой строке; тоже без крышки, `--no-lid`).

## Рекомендации по печати (Kobra S1)

- Печать плашмя дном вниз, поддержки не требуются.
- Высота слоя 0.2 мм; толщина стенок 2 мм ≈ 5 периметров при сопле 0.4 мм —
  для меньшей толщины стенок уменьшайте число периметров соответственно.
- Заполнение 15–20 % достаточно, так как модель — по сути короб с тонкими
  стенками и перегородками.
- Скругления внутренних углов отсеков (по умолчанию 3 мм) облегчают
  выемку мелких деталей пальцами.
- Крышка тоже печатается плашмя, без поддержек (юбка обращена вниз, к столу).
- Зазор посадки крышки (`--fit-clearance`, по умолчанию 0.2 мм) рассчитан
  на типичную точность FDM с калиброванным принтером; если крышка садится
  слишком туго или слишком свободно — подстройте это значение под свой
  принтер и пластик (PLA/PETG).
- Защёлки цепляются выступом высотой `--snap-height` (по умолчанию
  0.7 мм) за язычок, отделённый от юбки прорезями `--snap-arm-gap`
  (по умолчанию 1 мм — печатается чисто соплом 0.4 мм за 2-3 прохода;
  меньше 0.6 мм может залипнуть/не прорезаться). Если язычок открывается
  слишком туго или слишком легко — увеличьте/уменьшите `--snap-arm-gap`
  (шире прорезь ⇒ мягче язычок) или `--snap-height` (глубже зацеп ⇒
  туже защёлка). Для очень жёстких пластиков (ABS) увеличьте
  `--snap-arm-width`, чтобы язычок оставался прочным при более мягком
  зацепе, либо отключите защёлки через `--no-snap`.
- Петли шарнира (диаметр `--hinge-knuckle-diameter`, по умолчанию 7 мм)
  печатаются как горизонтальные цилиндры-навесы плашмя вместе с
  остальной деталью — при диаметре в этих пределах Kobra S1 печатает их
  без поддержек. Отверстие под шпильку и сама шпилька — с зазором
  `--hinge-pin-clearance` (по умолчанию 0.3 мм) для свободного вращения;
  если петли после сборки крутятся туго — увеличьте зазор или слегка
  раздайте отверстие сверлом подходящего диаметра.
- В качестве шпильки подойдёт отрезок стержня/прутка/спицы диаметром
  `--hinge-pin-diameter` (по умолчанию 3 мм) чуть длиннее ряда петель —
  напечатанная деталь `..._pin.stl` даёт готовый ориентир по размеру,
  но для прочности лучше использовать металлический стержень, а не
  напечатанный (тонкий печатный пруток на изгиб слабее).

## Органайзер для батареек AA/AAA и «таблеток» (нижняя часть)

`models/battery_organizer.py` → `stl/battery_organizer.stl`. Круглые гнёзда, стоят вертикально, уложены «сотами».
Габариты 194×103×26 мм, **76 гнёзд**:

- AA — 8×5 = **40** шт. (гнёзда 15 мм, глубина 26 мм)
- AAA — 4×7 = **28** шт. (гнёзда 11 мм, глубина 24 мм)
- плоские — передний ряд: 6 гнёзд Ø20,5 мм (CR2016/2025/2032) и 2 гнезда Ø25 мм (CR2450); глубина 18 мм ≈ 5 шт. CR2032 в стопке

Ускорение печати: стенка 1,2 мм (3 периметра сопла 0,4), нет сплошного дна — пол только под кольцами
гнёзд, щели между кольцами и у стенок сквозные; кольца AAA и «таблеток» ниже внешней стенки.
Без поддержек. Параметры: `--aa-cols --aa-rows --aaa-cols --aaa-rows --height --wall`;
диаметры плоских батареек — `coin_diameters` в `DEFAULTS`.
