# Коробка для хранения метизов

Параметрическая 3D-модель (CadQuery) органайзера для метизов — винтов,
гаек, шайб и т.п. Рассчитана на печать на **ANYCUBIC Kobra S1**
(рабочая область 250×250×250 мм, CoreXY) плашмя, без поддержек.

## Параметры

| Параметр | CLI-флаг | По умолчанию | Описание |
|---|---|---|---|
| Ширина коробки | `--width` | 190 мм | внешний размер по X |
| Длина коробки | `--length` | 130 мм | внешний размер по Y |
| Высота (глубина) коробки | `--height` | 30 мм | внешний размер по Z |
| Толщина стенок | `--wall` | 2 мм | толщина внешних стенок, дна и перегородок |
| Колонки отсеков | `--cols` | 4 | число ячеек по X |
| Строки отсеков | `--rows` | 6 | число ячеек по Y |
| Радиус скругления отсеков | `--radius` | 3 мм | скругление внутренних вертикальных углов каждой ячейки |
| Ширины колонок | `--col-sizes` | равномерно | список мм через запятую, переопределяет равное деление |
| Длины строк | `--row-sizes` | равномерно | список мм через запятую, переопределяет равное деление |

По умолчанию получается коробка 190×130×30 мм с сеткой 4×6 = 24 одинаковых
отсека.

Если заданы `--col-sizes` / `--row-sizes`, сумма значений должна точно
заполнять внутреннее пространство за вычетом перегородок:
`sum(sizes) == (внешний_размер − 2×толщина_стенки) − толщина_стенки×(N−1)`.
При несовпадении скрипт выбросит понятную ошибку с подсказкой.

## Установка

```bash
pip install -r requirements.txt
```

## Генерация STL

```bash
# модель по умолчанию (190x130x30, сетка 4x6)
python3 models/fastener_box.py --out stl/fastener_box_190x130x30_4x6.stl

# кастомные размеры и сетка
python3 models/fastener_box.py --width 200 --length 150 --height 40 \
  --wall 2.5 --cols 5 --rows 3 --radius 4 \
  --out stl/my_box.stl

# неравномерная сетка (разная ширина колонок / длина строк)
python3 models/fastener_box.py --cols 3 --rows 2 \
  --col-sizes 50,70,62 --row-sizes 60,64 \
  --out stl/fastener_box_example_asymmetric.stl

# дополнительно сохранить STEP для редактирования в CAD
python3 models/fastener_box.py --step stl/fastener_box.step
```

Модель также можно импортировать программно:

```python
from models.fastener_box import build_fastener_box

model = build_fastener_box(box_width=190, box_length=130, box_height=30,
                            wall_thickness=2, num_cols=4, num_rows=6,
                            corner_radius=3)
```

## Готовые STL в этом репозитории

- `stl/fastener_box_190x130x30_4x6.stl` — модель по умолчанию.
- `stl/fastener_box_example_asymmetric.stl` — пример неравномерной сетки
  отсеков (3×2, колонки/строки разной ширины).

## Рекомендации по печати (Kobra S1)

- Печать плашмя дном вниз, поддержки не требуются.
- Высота слоя 0.2 мм; толщина стенок 2 мм ≈ 5 периметров при сопле 0.4 мм —
  для меньшей толщины стенок уменьшайте число периметров соответственно.
- Заполнение 15–20 % достаточно, так как модель — по сути короб с тонкими
  стенками и перегородками.
- Скругления внутренних углов отсеков (по умолчанию 3 мм) облегчают
  выемку мелких деталей пальцами.
